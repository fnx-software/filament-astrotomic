## ✨ What's New

This patch release fixes `TranslatableTabs` rendering and locale handling in Filament v5. Unlike the earlier `v2.2.0` tag, this version includes the verified native tabs fix and multilingual persistence tests.

### Added

* SQLite-backed tests confirming Create/Edit of Arabic and English Astrotomic translations and preservation of hidden French translations.
* Automated Pest, PHP syntax, and Laravel Pint checks on PHP 8.3 and PHP 8.4.

### Changed

* `TranslatableTabs` and `AdvancedTabs` use Filament 5's native embedded tab renderer.
* Prefix/suffix actions, including the locale picker, appear in a toolbar above the language tabs.
* Single-locale forms render their fields directly without a redundant tab bar.

### Fixed

* Translation tabs displaying without their form fields.
* Missing legacy `filament-schemas::components.grid` Blade view.
* Livewire locale picker state handling.
* Hidden languages inadvertently losing draft state or saved translation records.
* Standalone Testbench setup for Filament, Astrotomic locales, and test-only encryption.

### Example

```php
use Filament\Forms\Components\TextInput;
use Fnxsoftware\FilamentAstrotomic\Schemas\Components\TranslatableTabs;
use Fnxsoftware\FilamentAstrotomic\TranslatableTab;

TranslatableTabs::make('Translations')
    ->customLocales(['en', 'ar'])
    ->force()
    ->localeTabSchema(fn (TranslatableTab $tab): array => [
        TextInput::make($tab->makeName('name'))
            ->required($tab->isMainLocale())
            ->maxLength(255),
    ]);
```

### Notes

* Use `TranslatableTabs` instead of the unreleased `LocaleAwareTranslatableTabs` / `TranslatableLocaleTabs` alternatives.
* No database migration is required.
* `TranslatableSelect`, `TranslatableColumn`, and `TranslatableEntry` are unchanged.
* Automated package verification: **8 passing tests, 29 assertions**, on each of PHP 8.3 and 8.4.
* Test Create/Edit, RTL, and the locale picker in your consuming application before deploying to production.
